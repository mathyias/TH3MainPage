# TH3MainPage

Official landing page for TH3Chain.

## Live site

https://th3chain.cloud

## What it shows

- TH3Chain overview
- TH3 Core infrastructure
- Wallet, explorer, API and mining links
- AWS node layout
- Seed node information
- Live network and pool status

## Connected services

- Wallet: https://wallet.th3chain.cloud
- Explorer: https://explorer.th3chain.cloud
- API: https://api.th3chain.cloud/api/network
- Mining: https://miner.th3chain.cloud
- Pool API: https://pool.th3chain.cloud/api/pool/stats

## Repository

This is a static HTML/CSS/JS frontend deployed through Cloudflare Pages.
