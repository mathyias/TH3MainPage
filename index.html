SELF-CUSTODY POW NETWORK

TH3Chain is a Ravencoin-based Proof-of-Work UTXO chain with a live explorer, public API, and browser wallet. TH3 Wallet builds and signs transactions locally, then broadcasts signed raw transactions through the TH3 API.

What Works Now

The core user flow is live: create or import a seed phrase, generate a TH3 address, receive UTXO, sign locally, broadcast, and inspect the confirmed transaction in Explorer.

01

TH3 Wallet

Seed phrase wallet with password lock, import, QR code, balance, history, send UI, and auto refresh.

02

Local Signing

Transactions are built from UTXO and signed inside the wallet. The seed and private key never go to the API.

03

Explorer

Blocks, addresses, UTXO and transaction details are visible through the public explorer.

04

Broadcast API

The API exposes network status, balances, history, UTXO and signed raw transaction broadcast.
