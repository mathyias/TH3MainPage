Live TH3 Stack

TH3 is now running as a live Proof-of-Work network. The ecosystem includes chain nodes, browser wallet, explorer, public API, mining page, pool statistics and automatic pool payouts.

01

TH3 Core

TH3 Core runs the live chain through th3d and th3-cli on production seed nodes.

02

TH3 Wallet

Seed phrase wallet with import, password lock, address generation, QR code, balance, history and send flow.

03

Local Signing

Wallet transactions are built from UTXO data and signed locally before broadcast through the TH3 API.

04

TH3 Explorer

Blocks, transactions, addresses, UTXO, mining rewards and confirmations are available through the explorer.

05

TH3 API

Public endpoints expose network status, address balance, rich history, UTXOs, transactions and raw broadcast.

06

TH3 Pool

The public KAWPOW pool is online with miner tracking, live shares, valid blocks and automatic payouts.
