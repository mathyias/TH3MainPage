TH3CHAIN

Wallet. Explorer. Mining. API.

TH3Chain is a Ravencoin-based Proof-of-Work UTXO network with a self-custody browser wallet, live explorer, public API, mining support, AWS and Oracle seed nodes. TH3 Wallet builds and signs transactions locally, then broadcasts signed raw transactions through the TH3 API.

Live TH3 Stack

The core chain stack is already connected: wallet, explorer, API, mining, internal pool, UTXO history, broadcast endpoint and seed infrastructure.

01

TH3 Wallet

Seed phrase wallet with import, password lock, QR code, balance, history, send UI, fee display and auto refresh.

02

Self-Custody Send

Transactions are built from UTXO and signed locally. Seed and private key never leave the wallet.

03

TH3 Explorer

Blocks, addresses, UTXO, mining rewards and transaction details are readable through the public explorer.

04

Mining Support

Mining rewards are tracked in wallet history, including immature rewards before they reach spendable maturity.

05

Public API

API exposes network status, balances, rich history, UTXO, transaction lookup and signed raw transaction broadcast.

Mining And Maturity

TH3Chain is mineable Proof-of-Work. Coinbase rewards appear in wallet history as mining rewards. Fresh mining rewards are marked as immature until they reach spendable maturity.

Mine block
Coinbase reward appears in wallet history
Immature reward waits for confirmations
Mature reward becomes spendable UTXO
