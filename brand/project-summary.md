# TH3Chain Project Summary

TH3Chain is a live independent Proof-of-Work blockchain using the KAWPOW mining algorithm.

The project includes a public website, browser wallet, block explorer, API, and public mining pool. TH3Chain uses native TH3-prefixed addresses and supports public mining through a KAWPOW stratum pool.

## Network

- Ticker: TH3
- Consensus: Proof of Work
- Algorithm: KAWPOW
- Address prefix: TH3
- Block reward: 2137 TH3
- Public mining: active
- Automatic pool payouts: active
