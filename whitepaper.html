TH3Chain

TH3Chain is a live independent Proof-of-Work blockchain using the KAWPOW mining algorithm, TH3-prefixed addresses, a browser wallet, public explorer, API and mining pool.

1. Overview

TH3Chain is a community-launched native cryptocurrency network built around open Proof-of-Work mining. The chain uses the Bitcoin UTXO model and KAWPOW mining, with public infrastructure available for wallets, block exploration, API access and pool mining.

The project goal is to provide a simple, transparent and mineable blockchain with public tools that allow users to create wallets, mine TH3, inspect blocks and transactions, and follow network activity.

3. Mining

TH3Chain uses KAWPOW, a GPU-oriented Proof-of-Work algorithm. Public mining is available through the official TH3 mining pool.

Stratum Endpoint stratum+tcp://pool.th3chain.cloud:3333

Miners use their TH3 wallet address as the username. Rewards are tracked using accepted shares and automatically paid after the configured confirmation buffer and minimum payout threshold.

4. Reward Distribution

Pool rewards are first received by the pool wallet as block rewards. After blocks mature, the payout system calculates each miner's share of the payable reward period.

  • Accepted shares are used to calculate each miner's contribution.
  • The pool fee is deducted from the gross block reward.
  • The remaining miner reward is split proportionally by accepted shares.
  • Payouts are sent automatically when the minimum payout threshold is reached.

5. Supply Model

TH3 has a fixed emission model based on block rewards and halvings. The block reward starts at 2137 TH3 and halves every 2,100,000 blocks.

The approximate maximum emission is 8,975,400,000 TH3. The code-level monetary validation cap is higher than the actual expected emission and acts as a safety limit, while real emission is determined by block subsidy and halving rules.

7. Security And Transparency

TH3Chain is secured by Proof-of-Work mining. Transactions, blocks and addresses can be inspected through the public explorer. The network is designed around open mining, public statistics and transparent pool payouts.
