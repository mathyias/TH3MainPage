Overview

TH3Chain is a community-launched native cryptocurrency network built around open Proof-of-Work mining, public infrastructure and simple wallet access.

Independent chainPublic explorerOpen wallet
02

Mining

TH3Chain uses KAWPOW, a GPU-oriented Proof-of-Work algorithm. Public mining is available through the official pool.

pool.th3chain.cloud:3333KAWPOW
03

Reward Distribution

Block rewards are produced by miners and paid through the public network. Pool payouts are visible through the TH3Chain explorer.

2137 TH3On-chain payoutsExplorer visible
04

Supply Model

Supply is created by mining. Public API endpoints expose current circulating, total and max supply data for trackers and integrations.
