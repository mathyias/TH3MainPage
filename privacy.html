PRIVACY POLICY

TH3 Wallet

Privacy details for the TH3 Wallet browser extension and its use of local wallet data, public TH3 addresses, signed transactions and TH3Chain API access.

Open Wallet Whitepaper
Last UpdatedJune 14, 2026

TH3 Wallet is a browser wallet for TH3Chain. It lets users create or import a wallet, view balances, receive TH3 and sign/send transactions.

01

Data Stored Locally

Wallet data is stored locally in the browser. TH3 Wallet does not send seed phrases, private keys or passwords to TH3Chain servers.

Local walletEncrypted dataNo server keys
02

API Requests

The wallet may send public addresses and transaction data to the TH3Chain API to fetch balances, UTXOs, history and broadcast signed transactions.

03

We Do Not Collect

  • Private keys or seed phrases.
  • Wallet passwords.
  • Personal identity documents.
  • Advertising profiles.
04

Third Parties

TH3 Wallet connects to TH3Chain infrastructure such as the public API and explorer. Public blockchain data may be visible on the TH3Chain network and explorer.

05

Contact

Questions about privacy, wallet behavior or public infrastructure can be sent to the official TH3Chain contact address.

contact@th3chain.cloud
